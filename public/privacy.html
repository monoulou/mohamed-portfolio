Privacy Policy

Hermes Moh, personal automation tool. Last updated: October 20, 2026.

What this application is

Hermes Moh is a private, single-user automation tool operated by Mohamed Abdelmoumen for his own use. It is not offered to the public and has no other users. It is the OAuth client that lets this tool access the operator's own Google account.

Google data accessed

With the operator's explicit consent, the tool may access the following data of his own Google account:

  • Google Drive, Docs and Sheets: read and write files used for personal job search tracking.
  • Gmail: read messages, apply labels, and send emails on the operator's behalf.
  • Google Calendar: read and create events.
  • Google Contacts: read only.

How the data is used

  • Data is used only to automate the operator's own tasks (job applications log, drafts, scheduling).
  • Some content may be processed by an AI model provider (Anthropic, Claude API) to draft text. It is not used for advertising.
  • No data is sold, rented or shared with third parties for any other purpose.
  • Use of data received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.

Storage and retention

OAuth tokens and working files are stored on a private server controlled by the operator, with access restricted to the operator. Working files are kept only as long as needed for the tasks above and can be deleted at any time.

Revoking access

Access can be revoked at any time from myaccount.google.com/permissions.
